音频缓存功能测试

缓存功能说明

这个页面用于测试音频缓存功能。缓存可以避免重复调用TTS API，提升响应速度并节省费用。

测试步骤

  1. 确保已正确设置OpenAI API Key
  2. 点击下面的测试段落进行朗读
  3. 观察是否显示"使用缓存的音频"或"生成新的音频"通知
  4. 重复点击同一段落，应该看到缓存通知
  5. 在插件弹窗中查看缓存状态

缓存管理测试

缓存状态检查

在插件弹窗中查看以下信息：

  • 缓存状态：显示"空"、"已加载"或"错误"
  • 缓存条目：显示当前缓存数量（如：15/50）
  • 清空缓存：点击按钮清空所有缓存
  • 清理过期：清理超过24小时的缓存

缓存优势说明

🎯 主要优势

  • 响应速度：缓存的音频可以立即播放，无需等待API调用
  • 成本节省：避免重复的API调用，减少OpenAI费用
  • 用户体验：重复朗读同一内容时响应更快
  • 网络优化：减少网络请求，特别是在网络较慢的情况下

🔧 技术特性

  • 智能缓存键：基于文本内容、语音和速度生成唯一缓存键
  • 自动清理：支持24小时自动过期和手动清理
  • 容量控制：最多缓存50个音频条目，防止内存占用过多
  • 状态同步：缓存状态在插件界面实时显示
