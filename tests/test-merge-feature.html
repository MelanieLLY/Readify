段落合并功能测试

测试说明

这个页面用于测试段落合并功能。每个段落都有不同长度，点击段落后的喇叭图标应该会：

  • 如果段落长度不足450字符，会自动合并后续段落
  • 合并后的文本会一起发送到TTS API
  • 图标状态会显示在最后一个被合并的段落后面
